勾选后按仓库 URL 从系统凭据管理器取 PAT，无需在此填写。DPAPI 与凭据管理器底层同级，此选项的价值是便利与单一来源，不是安全升级。

安全须知

· 密钥遗忘 = 数据永久不可解密。本工具不保存明文密钥的可恢复副本。
· 远端 profiles/{syncId}.enc 为密文，没有密钥无法解读。
· 多机同时上传同一同步 ID 为"后写者胜"，请避免并发修改同一变量集合。
· 上传为整体覆盖而非增量合并，payload 只含本次勾选的变量。

就绪
仅用户变量 HKCU · 仅 HTTPS + PAT · 变量改动对新建进程生效 · 密钥遗忘 = 数据永久不可解密

这是交互原型

数据为演示用，不会读写真实仓库或注册表。可试：

  • 点 拉取远端 → 骨架屏 → 变量列表与差异出现
  • 切换某行勾选框 → 状态胶囊与概览计数实时变化
  • 点行 → 展开本机值 / 远端值对照
  • 应用到本机 / 上传 → 确认弹窗 → 进度 → Toast
  • 本机变量页删除 → 可撤销 Toast；高危变量走二次确认
  • 搜索、状态筛选、页面对角切换、Tab 键遍历焦点
